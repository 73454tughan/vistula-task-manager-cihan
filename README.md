## 3. Technology Stack & Database Setup
- **Frontend:** Semantic HTML5, responsive CSS3, vanilla modern JavaScript (Fetch API).
- **Backend/Database:** Supabase (PostgreSQL) REST API.
- **Table Name:** `tasks`
- **Schema:**
  - `id`: BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY
  - `title`: TEXT NOT NULL
  - `description`: TEXT
  - `completed`: BOOLEAN DEFAULT false
